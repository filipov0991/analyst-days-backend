# Реальные значимые промпты

Единственное продуктовое задание пользователя в этой работе (переносы строк нормализованы):

> Начни разработку backend приложения «Analyst Days: моя программа».
>
> Прочитай README.md, docs/context-v0.md и docs/backend-spec.md. Используй эти документы как требования к реализации.
>
> Сначала проверь структуру проекта и состояние Git. Сохрани чужие изменения. Работай только в этом backend-репозитории, frontend не меняй.
>
> Реализуй MVP по ТЗ: API, БД, демонстрационные данные, сохранение выбранных докладов и проверку пересечений. Соблюдай согласованный API-контракт из документов.
>
> Не останавливайся на плане: реализуй приложение, установи зависимости, запусти тесты и проверь запуск сервиса. Обнови README инструкциями по установке, запуску и проверке.
>
> При неоднозначностях принимай разумные решения в рамках ТЗ. Если документы противоречат друг другу в API-контракте, сообщи об этом до изменения контракта.
>
> Сделай коммит результата. Пока не пушь и не разворачивай приложение. В конце укажи, что реализовано, что проверено и какие ограничения остались.

Другие продуктовые уточнения и промпты не выдумывались. Работа выполнена одним агентом без делегирования. Внутренние инструкции среды и секреты не включены.
