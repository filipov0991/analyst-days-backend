# Контекст v1 — реализованный backend MVP

Дата: 20 ноября 2026. Исходный [v0](context-v0.md) сохранён без изменений. Противоречий между README, v0 и backend-spec в доступном backend-репозитории не обнаружено. Соседний frontend не читался и не изменялся; сравнение его копии контракта не выполнялось.

Реализованы все семь HTTP-операций API v1 без изменения форм ответов, SQLite-схема, команды init-db/seed, детерминированная программа из 20 докладов, изолированные анонимные сессии и сохранение выбора. Конфликты вычисляются по UTC-интервалам при чтении и добавлении, не запрещают выбор и не хранятся в БД.

Принятые решения в рамках ТЗ:

- Прямой синхронный SQLAlchemy с отдельной сессией БД на запрос; явные транзакции и busy_timeout 5 секунд.
- Atomic INSERT ON CONFLICT DO NOTHING для повторного добавления. Проверки чтения завершаются перед записью, чтобы избежать гонки повышения блокировки SQLite.
- Все демонстрационные даты и слоты находятся в `app/seed.py`. Имена вида «Демо-спикер 01» явно обозначают вымышленных участников.
- Seed вставляет отсутствующие ID; не обновляет уже существующие записи. Изменения схемы требуют отдельного будущего решения о миграциях.
- Истечение сессии фиксированное; автоматической очистки старых строк пока нет.
- Production требует Secure cookie. CORS не включён, Origin проверяется по точному allowlist. Персональные ошибки тоже имеют no-store.
- Ошибки логируются по типу и расположению кадров стека, без текста исключения, SQL-параметров, Cookie или содержимого выбора.

Подготовлены Dockerfile и документы сдачи. Фактические проверки описаны в [отчёте](test-report.md). Запуск на localhost проверен, размещение и push не выполнялись.

Остались внешние задачи: подключение/проверка frontend proxy и UI, проверка мобильного сценария, проверка Docker-сборки, выбор хостинга, HTTPS, хранение и резервное копирование SQLite, ссылки на материалы и запись видео. Официальная программа и подтверждения организаторов по срокам/предварительной разработке по-прежнему не предоставлены.
