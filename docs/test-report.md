# Отчёт backend-проверок

Актуализация: совместная проверка выполнена 20 ноября 2026 — [результаты](integration-checks.md). Ниже сохранён исходный отчёт этапа разработки; его пометки об отложенной интеграции больше не актуальны.

Дата: 20 ноября 2026. Среда: macOS arm64, Python 3.12; точные версии библиотек зафиксированы в requirements.txt.

## Автоматические проверки

`python -m pytest -q`: **37 passed**. Тесты используют временные SQLite-файлы и независимые cookie-клиенты.

| Детали и ошибки | Одинаковый Talk в списке/деталях, 404, 422, безопасные details |
| Выбор | Добавление, повтор, удаление и повторный DELETE, 204 без тела |

| БД | UTC round-trip через SQLite и JSON, соответствие московскому дню, FK, CHECK длительности, каскадное удаление, busy_timeout |

`python -m pip check`: **No broken requirements found**.

Осталось предупреждение Starlette: использование httpx в TestClient deprecated, рекомендуется httpx2. Тесты проходят; предупреждение не скрыто. Смена тестового транспорта — отдельное обслуживание зависимости.

## Команды и реальный HTTP

- `python -m app.db init-db`: успешно создана локальная схема.
- `python -m app.seed`, выполнено дважды: успешно, каталог содержит 20 докладов.
- `uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log`: сервис запущен локально.
- `python scripts/smoke.py`: успешно. Проверены health, HTTP 200 `/docs`, `/openapi.json`, каталог, новая сессия, выбор 1/2, повторный PUT, два конфликтующих доклада, DELETE 204 и исчезновение конфликта.
- `git diff --check`: без ошибок пробелов.

При первоначальной установке sandbox блокировал сеть, а при запуске — bind/connect localhost. После разрешения выполнения вне этих ограничений зависимости установлены и HTTP-проверка выполнена. Первая попытка pytest выявила коллизию имени типа `date` с полем ORM; исправлено до успешного прогона.

## Что не проверялось

- UI Swagger в браузере: проверена выдача HTML и схема, не интерактивный Try it out.
- Сквозной frontend proxy/UI, мобильный сценарий и гипотеза «три доклада за две минуты».
- Docker build/run, Linux и публичное развёртывание.
- Нагрузочная эксплуатация, восстановление резервных копий, длительная работа под production-нагрузкой.

Проверка сохранения после пересоздания приложения автоматизирована; отдельный сценарий завершения ОС-процесса с последующим восстановлением той же браузерной cookie не выполнялся.
